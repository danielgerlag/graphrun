# graphrun-cli

Production CLI for [graphrun](https://crates.io/crates/graphrun). This crate installs the `graphrun` binary.

```sh
cargo install graphrun-cli --locked
```

```sh
graphrun validate \
  --definition sequence.yaml \
  --catalog activity-catalog.json
```

Specs, quickstarts, and examples: <https://github.com/danielgerlag/graphrun>
